\noindent \textbf{摘要：} 随着《义务教育课程方案（2022年版）》的颁布，基础教育课程改革进入核心素养时代。新课标强调“做中学”、“用中学”与“创中学”，要求通过真实情境下的项目实践培养学生的数字素养。本文针对当前信息科技教学中情境创设浅表化、技术实践低幼化的痛点，提出并实现了一种基于“智能身后事管理系统”（EBYZ）的跨学科项目式学习（PBL）模式。

该系统构建了一个从边缘感知到云端认知的全栈物联网（AIoT）教学平台，创新性地融合了OpenWrt边缘计算、Supabase云原生架构以及RAG 2.0（检索增强生成）人工智能技术。在技术路线上，本文详细阐述了基于层级化索引（Hierarchical Indexing）的知识库构建、混合检索（Hybrid Search）算法优化以及“通灵协议”中的提示工程策略。

教学实践表明，该模式通过极具张力的“数字陵墓”隐喻，有效激发了学生的探究兴趣，在解决“断网保活”、“数字遗产继承”等真实复杂问题中，显著提升了学生的信息意识、计算思维、数字化学习与创新及信息社会责任，为新时代信息科技教育提供了具有前瞻性的范式参考。

\section{引言}
\subsection{研究背景}
数字化生存已成为当代青少年的基本生存方式。2022年版《义务教育信息科技课程标准》明确指出，信息科技课程应从单纯的操作技能训练转向学科核心素养的培育，倡导基于真实情境的项目式学习\cite{moe2022}。然而，现有的教学实践中常存在“假项目”、“浅探究”现象，学生往往在简化的模拟环境中操作，缺乏对真实技术复杂性的体验与应对。

\subsection{研究意义}
本研究试图打破常规，引入“智能身后事管理系统”（Project EBYZ: EveryBody YingZheng）这一具有强烈冲击力与哲学思辨性的主题。通过构建一个包含感知、传输、处理、控制与反馈闭环的全栈物联网系统，让学生在“为自己构建数字来世”的极端情境中，深入理解物联网协议的鲁棒性、数据隐私的边界以及人工智能的伦理挑战。

\begin{itemize}
    \item \textbf{协议转换}：将Zigbee 3.0协议帧解包，转换为标准的JSON格式MQTT Payload。
    \item \textbf{设备解耦}：上层应用只需订阅 \texttt{zigbee2mqtt/\#} 主题，无需关心底层硬件差异。

\begin{enumerate}

    \item \textbf{本地消息队列}：部署Mosquitto Broker，实现局域网内的低延迟设备通信（<10ms）。
\end{enumerate}

\subsubsection{PDF解析与结构化提取}
系统首先通过 \texttt{pdf-extraction} 库解析教材PDF，提取原始文本。核心代码如代码清单\ref{code:extract}所示：

\begin{lstlisting}[language=Python, caption=知识库提取脚本（extract.cjs）, label=code:extract]
const fs = require('fs');
const path = require('path');
const pdf = require('pdf-extraction');

// 解析文件名元数据
function parseFilename(filename) {
  const parts = filename.replace('.pdf', '').split('+');
  let grade = '未知年级';
  let subject = '未知科目';
  
  parts.forEach(part => {
    if (part.includes('六年级')) grade = '六年级';
    if (part.includes('七年级')) grade = '七年级';
    if (part.includes('八年级')) grade = '八年级';
    
    if (part.includes('过程与控制')) subject = '过程与控制';
    if (part.includes('互联网')) subject = '互联网应用与创新';
    if (part.includes('物联网')) subject = '物联网实践与探索';
  });
  
  return { grade, subject };
}

// 基于文档结构的智能分块
function chunkTextByStructure(text, baseMetadata) {
  const chunks = [];
  // 正则匹配单元标题：如"第一单元"、"模块一"
  const unitRegex = /(第[一二三四五六七八九十]+单元|模块[一二三四五六七八九十]+)\s*[:：]?\s*([^\n]+)?/g;
  
  let match;
  let lastIndex = 0;
  let lastUnitTitle = '前言/概述';
  
  while ((match = unitRegex.exec(text)) !== null) {
    const startIndex = match.index;
    const unitName = match[0];
    
    // 保存前一个分块
    if (startIndex > lastIndex) {
      const content = text.substring(lastIndex, startIndex).trim();
      if (content.length > 100) {
        chunks.push({
          id: `${baseMetadata.grade}_${chunks.length}`,
          content: content,
          metadata: {
            ...baseMetadata,
            unit: lastUnitTitle,
            type: 'section',
            length: content.length
          }
        });
      }
    }
    
    lastIndex = startIndex;
    lastUnitTitle = unitName.trim();
  }
  
  // 添加最后一个分块
  if (lastIndex < text.length) {
    const content = text.substring(lastIndex).trim();
    if (content.length > 100) {
      chunks.push({
        id: `${baseMetadata.grade}_${chunks.length}`,
        content: content,
        metadata: {
          ...baseMetadata,
          unit: lastUnitTitle,
          type: 'section',
          length: content.length
        }
      });
    }
  }
  
  return chunks;
}
\end{lstlisting}

\subsubsection{树状索引结构}
系统将非结构化文本转化为结构化的JSON树，形成“年级 $\rightarrow$ 单元 $\rightarrow$ 课时 $\rightarrow$ 知识块”的层级关系：
\begin{equation}
    \text{Index Tree} = \text{Grade} \xrightarrow{} \text{Unit} \xrightarrow{} \text{Lesson} \xrightarrow{} \text{Chunks}
\end{equation}
每个知识块（Chunk）包含：
\begin{itemize}
    \item \textbf{ID}：唯一标识符（如 \texttt{六年级\_0}）
    \item \textbf{Content}：实际文本内容（限制最大8000字符，防止上下文溢出）
    \item \textbf{Metadata}：元数据字典，包括年级、科目、单元标题、内容长度等
\end{itemize}

\subsection{混合检索算法（Hybrid Search Strategy）}
\subsubsection{三级过滤策略}
在教案生成时，系统采用三级过滤策略，确保检索的精确性与效率：

\begin{lstlisting}[language=Python, caption=RAG检索核心逻辑（LessonDetail.tsx）, label=code:rag-retrieve]
// 1. 元数据硬过滤：根据年级快速缩小范围
const targetGrade = module.grade.split('：')[0]; // e.g. "六年级"
const titleKeywords = lesson.originalTitle
  .replace(/第.+[课|节|章]/g, '').trim(); // e.g. "过程与控制"

// 第一级：按年级过滤（Metadata Filtering）
const gradeChunks = (data as any[] || []).filter(chunk => {
  if (chunk.metadata && chunk.metadata.grade) {
    return chunk.metadata.grade === targetGrade;
  }
  return chunk.content.includes(targetGrade);
});

// 第二级：模糊匹配课程标题关键词
const relevantChunks = gradeChunks.filter(chunk => {
  const unitMatch = chunk.metadata?.unit && 
    chunk.metadata.unit.includes(titleKeywords);
  const contentMatch = chunk.content.includes(titleKeywords);
  return unitMatch || contentMatch;
});

// 第三级：回退策略（Fallback）
const finalChunks = relevantChunks.length > 0 
  ? relevantChunks 
  : gradeChunks.slice(0, 5); // 限制为前5个，避免上下文溢出
\end{lstlisting}

\subsubsection{混合检索公式}
为了提高检索的召回率（Recall）与准确率（Precision），系统结合了稀疏检索与稠密检索：

\begin{equation}
    Score(q, d) = \alpha \cdot \text{BM25}(q, d) + (1-\alpha) \cdot \text{Cosine}(E(q), E(d))
\end{equation}

其中：
\begin{itemize}
    \item \textbf{稀疏检索（BM25）}：匹配教案标题中的关键词（如“传感器”、“Python”），确保核心术语的精确匹配。
    \item \textbf{稠密检索（Dense Retrieval）}：使用 \texttt{text-embedding-3-small} 模型将查询意图向量化，计算与知识块向量的余弦相似度，捕捉语义层面的相关性（如“环境监测”与“温湿度”的关联）。
    \item \textbf{动态重排序（Re-ranking）}：对混合检索结果进行加权排序，选取Top-K个最相关的知识块作为上下文。
\end{itemize}

\subsubsection{上下文注入与截断策略}
为防止大模型上下文窗口溢出，系统对每个知识块进行智能截断：

\begin{lstlisting}[language=Python, caption=上下文构建与截断, label=code:context]
knowledgeContext = finalChunks
  .map(chunk => {
    // 智能截断：超过8000字符则截断并添加省略号
    const content = chunk.content.length > 8000 
      ? chunk.content.substring(0, 8000) + '...' 
      : chunk.content;
    const unitTitle = chunk.metadata?.unit || chunk.filename || '参考资料';
    return `[参考资料: ${unitTitle}]\n${content}`;
  })
  .join('\n\n');
\end{lstlisting}

\section{课程实施与评价体系}
\subsection{教学活动设计案例}
以八年级“数字遗嘱智能生成”项目为例：
\begin{itemize}
    \item \textbf{需求分析}：如何确保遗嘱只在特定条件下（如确认死亡）触发？
    \item \textbf{技术实现}：结合心跳传感器数据（MQTT输入）与逻辑判断（Python代码），调用AI接口生成遗嘱内容。
    \item \textbf{伦理讨论}：数字资产的继承权归属讨论。
\end{itemize}

\subsection{基于DAO的多元评价机制}
平台构建了“封神榜”评价系统，引入了Web3.0的DAO（去中心化自治组织）治理理念：
\begin{itemize}
    \item \textbf{创造力证明（Proof of Creativity）}：学生的贡献度（功德值）由算法自动计算。
    \begin{equation}
        \text{Merit} = \log(1 + \text{Likes}) + \beta \cdot \text{Remixes} + \gamma \cdot \text{QualityScore}
    \end{equation}
    其中 \text{Remixes} 代表被他人二创引用的次数，权重 $\beta$ 较高，旨在鼓励开源与分享精神。
    \item \textbf{版本溯源树}：利用Git思想记录教案的衍生路径，形成知识图谱，直观展示创意的流动与进化。
\end{itemize}

\section{核心素养的达成度分析}
本项目有效促进了学生核心素养的达成，具体体现在：

\subsection{信息意识}
学生通过物联网数据收集（如温湿度传感器），评估数据来源可靠性，形成对信息价值的敏感度。例如，在“数字遗嘱”模块中，学生辨别数据主权问题，强化信息安全意识。

\subsection{计算思维}
学生在算法设计（如防盗墓逻辑）中运用分解、模式识别等思维方法，契合计算思维作为“运用计算机科学思想解决问题”的定义。

\subsection{数字化学习与创新}
通过修改开源代码、训练AI模型，学生从技术使用者转变为创造者，体现“做中学”的创新精神。

\subsection{信息社会责任}
项目引导学生反思技术伦理（如AI“复活”的合理性），培养“有担当”的时代新人品质。学业质量标准显示，学生能在真实情境中综合运用知识，达成素养进阶。

\section{结论与展望}
本研究通过构建EBYZ全栈物联网教学平台，探索了一条融合前沿技术与深层人文思考的信息科技教育新路径。实践证明，高阶思维的培养需要高阶技术的支撑，RAG 2.0等AI技术的引入，不仅赋能了教师的教，更重塑了学生的学。

未来，我们将进一步拓展系统的边界：
\begin{enumerate}
    \item \textbf{多模态交互}：引入语音克隆与虚拟人技术，实现更逼真的“数字复生”体验。
    \item \textbf{脑机接口（BCI）探索}：研究基于脑电波（EEG）的物联网控制，探索“意念控制”在无障碍辅助设备中的应用。
    \item \textbf{区块链存证}：将学生的数字成果上链，颁发不可替代通证（SBT），构建终身学习的数字认证体系。
\end{enumerate}
