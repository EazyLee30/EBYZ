# EBYZ - EveryBody YingZheng

人均嬴政白皮书 - 智能棺材全栈物联网教学平台

## 项目简介

这是一个全栈物联网教学平台项目，集成了智能棺材相关的技术教学内容。

## 运行项目

**环境要求：** Node.js

### 本地开发

1. 安装依赖：
   ```bash
   npm install
   ```
2. 设置环境变量：
   - 创建 `.env.local` 文件
   - 设置 `GEMINI_API_KEY` 为你的 Gemini API 密钥
3. 运行开发服务器：
   ```bash
   npm run dev
   ```

### 构建生产版本

```bash
npm run build
```

### 预览生产构建

```bash
npm run preview
```

## 技术栈

- React 19
- TypeScript
- Vite
- Google Gemini AI
